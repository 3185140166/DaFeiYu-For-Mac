## Integration

Original selected images are preserved in this directory. prepare_hoodie_art.swift uses the new relaxed idle and preserves the prior happy pose. Both are padded to 896×640; header/icon sources remain square. prepare_hoodie_motion.swift slices the sheets into eight frames per direction, removes low-alpha saturated edge fringe, uniformly scales without cropping, and aligns face centroids to the idle sprite. A shared scale retains relative size. The wider transparent canvas preserves the trailing tail during turns; the rendered character height is unchanged. Walking uses the illustrated sheets rather than the previous front-facing leg rig. A 0.16s crossfade returns to the front view when stopping. The preparation script re-typesets detected name badges as Claude to correct generated lettering; small linework variations may remain across frames; the original artwork and earlier derivatives remain available.
